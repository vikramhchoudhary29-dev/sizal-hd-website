# Sizal HD Website - Module 1

Premium Next.js foundation for Sizal HD Lenses.

## Included

- Next.js app structure
- Tailwind CSS
- Locked folder structure
- Premium navbar
- Footer
- Reusable UI components
- Homepage foundation sections
- Admin route placeholders

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000
